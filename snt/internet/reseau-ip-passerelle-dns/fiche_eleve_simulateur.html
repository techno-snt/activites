Guide du simulateur

  • Mode conception / mode simulation : le bouton « ▶ Mode simulation » est au-dessus du plan. En simulation, le plan est verrouillé et le panneau Configuration n'apparaît plus.
  • Régler une machine : en mode conception, cliquez sur l'appareil, puis réglez son adresse, sa passerelle et son DNS dans le panneau Configuration.
  • Ouvrir le bureau d'une machine : cliquez sur l'appareil dans le plan. Le bureau propose Installation des logiciels, la Ligne de commande et, une fois installé, le Navigateur web.
  • Serveur DNS : son bureau contient l'application Serveur DNS. Dans Adresse (A), saisissez un nom et son adresse IP, puis cliquez sur Ajouter. Le bouton Démarrer le service est dans la même fenêtre : un service arrêté ne répond à aucune machine.
  • Vitesse des paquets : le curseur au-dessus du plan ralentit ou accélère les paquets.
